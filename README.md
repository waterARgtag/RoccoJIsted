# Rocco J Isted website

Ready for GitHub Pages. HTML, CSS and JavaScript are in index.html.

1. Unzip this package.
2. Upload index.html and all .webp image files into the top level of your GitHub repository. Do not upload the ZIP itself.
3. Keep the filenames exactly as supplied; image filenames are case-sensitive.
4. In repository Settings > Pages, choose Deploy from a branch, branch main and folder / (root), then Save.
5. Open the site URL shown in Settings > Pages after deployment finishes.

On GitHub Free, use a public repository. GitHub Pages publishes a publicly accessible website; the previous ChatGPT Site preview remains private.

The booking form prepares an email to naomi@naomikisted.com and does not store submissions. The video uses a YouTube embed; links to the supplied Instagram, TikTok, Facebook and YouTube profiles are included.

The .nojekyll file tells GitHub Pages to serve these static files directly.
